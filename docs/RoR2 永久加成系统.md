# Risk of Rain 2 永久加成系统

本机 Steam 未安装《雨中冒险 2》，无法像 20MTD 那样从 `Assembly-CSharp` 导出物品表。本文按公开设计公式、官方中文本地化，以及本仓库 `catalog.json` 里的 17 位正式英雄目录整理。

DLC3《合金集群 / Alloyed Collective》之后物品和角色还在加。下表以**机制分层**为准；单件数值以游戏内描述为准。

Wiki 里现有的是模型和动作，不是物品数值。英雄目录见根目录 `catalog.json`，生成清单见 `games/risk-of-rain-2/survivors.generated.json`。

---

## 1. 系统分层

RoR2 的「永久」拆成两层，和 20MTD 正好反着来：

| 层级 | 是什么 | 何时生效 | 过局是否保留 |
| --- | --- | --- | --- |
| 角色解锁 | 新幸存者进选人栏 | 下一局可选 | 保留，**不加数值** |
| 物品解锁 | 新物品进掉落池 | 之后各局可能刷到 | 保留池子，当局没有就不生效 |
| 备选技能 | 该角色 4 个技能槽的变体 | 开局装上 | 解锁保留，负荷当局选 |
| 神器 | 改整局规则的开关 | 开局勾选 | 解锁保留，默认不强制开 |
| 月币 | 跨局货币 | 月店 / 月箱 / 浴池 | 保留 |
| 日蚀进度 | 该角色的 E1–E8 | 下一档日蚀 | 按角色保留 |
| 物品叠层 | 白 / 绿 / 红 / 黄 / 月 / 虚空 | 捡到后整局 | **过局清零** |
| 主动装备 | 1 个装备槽 | 捡到后整局 | 过局清零 |
| 角色等级 | 经验换生命和伤害 | 整局 | 过局清零 |

设计一句话：

`角色技能触发器 × 可无限叠的物品 × 难度系数（时间 / 关卡 / 人数）`

跨局成长几乎全是**把池子变大**，不是 20MTD 符文那种「每阶射速 +2%」。当局变强几乎全靠叠物品；只靠升级会输给敌人血量曲线。

## 2. 跨局永久：解锁，不加面板

### 2.1 幸存者

本仓库正式英雄 17 位（另有 2 个自定义模型，不算游戏内角色）。

| 角色 | 英文 | 来源 | 战斗身份 |
| --- | --- | --- | --- |

| 女猎人 | Huntress | 本体 | 移动中自动瞄准，吃攻速和暴击 |
| 盗贼 | Bandit | 本体 | 背后暴击、重置大招，吃爆发和重置 |

| 工匠 | Artificer | 本体 | 冰火雷法术，吃暴击、冷却、离子爆发 |
| 佣兵 | Mercenary | 本体 | 近战连段和冲刺，吃暴露、范围、冷却 |
| 雷克斯 | REX | 本体 | 自残换更强植物技能，吃回血和荆棘 |

| 漂泊者 | Drifter | 合金集群 | 废料袋和临时物品，偏当局经济 |

解锁新角色**不提高**已有角色的攻击或生命。它只改「下一局能选谁」。

### 2.2 技能负荷

每名幸存者固定 4 个槽：

| 槽 | 通常键位 | 设计职责 |
| --- | --- | --- |
| 主要 | 鼠标左键 | 无限用的触发器，决定你怎么叠攻速 / 暴击 / 击中特效 |
| 次要 | 鼠标右键 | 有冷却的补伤害或补控制 |
| 机动 | Shift | 位移、无敌帧、靠近或拉开 |
| 特殊 | R | 长冷却的规则技：重置、清场、变形态、改地图 |

备选技能解锁后，开局替换其中一槽。换的是**触发器类型**，不是又一个 +5%。

例如突击兵把压制射击换成破片手雷，物品引擎从「高频命中」变成「范围爆炸」；盗贼把「一击必杀」换成「亡命之徒」，击杀重置变成叠层赌暴击。

### 2.3 物品解锁

没解锁的物品不会进宝箱池。解锁条件通常是：

- 捡到过一次并完成日志
- 完成某项挑战（无伤传送门、限时通关、某角色通关）
- 买对应 DLC

这和 20MTD 符文不同：解锁「士兵注射器」不会让你开局自带攻速，只是以后宝箱**有可能**刷到它。

### 2.4 月币

月币跨局保留。用来：

- 在时空集市买月物品 / 月装备
- 开月箱
- 用净化池把月物品洗成珍珠
- 复活（部分场景）

月币是唯一「跨局直接花掉、当局立刻变强」的货币。花完就没了，不会变成永久射速。

### 2.5 神器

解锁后在开局面板勾选，改整局规则。常用的：

| 神器 | 英文 | 改什么 |
| --- | --- | --- |
| 命令 | Command | 宝箱变成三选一，当局构筑从赌变成选 |
| 牺牲 | Sacrifice | 不再出箱子，击杀掉物品 |
| 荣耀 | Honor | 全精英，掉落和压力同时上升 |
| 玻璃 | Glass | 伤害 ×5，生命 ×0.1，和月物品「塑形玻璃」同族 |
| 蜂群 | Swarms | 敌人更多更脆 |
| 血亲 | Kin | 整关一种怪 |
| 不谐 | Dissonance | 混进其他关卡的敌人 |
| 进化 | Evolution | 每关敌人获得物品 |
| 复仇 | Vengeance | 定时刷出带你物品的分身 |
| 死亡 | Death | 一人死全队死 |
| 灵魂 | Soul | 击杀出幽魂 |
| 怨恨 | Spite | 敌人死亡爆炸 |
| 脆弱 | Frailty | 掉落伤害更狠 |
| 混沌 | Chaos | 友军伤害 |
| 谜团 | Enigma | 装备每次随机 |
| 变形 | Metamorphosis | 每关随机角色 |
| 奉献 | Devotion | 风暴探寻者：利莫里亚随从 |

神器是「规则开关」，不是数值阶。命令 + 牺牲会彻底改物品经济。

### 2.6 日蚀 E1–E8

按角色解锁。难度系数按 **3.5** 算，并逐层叠惩罚：

| 层 | 惩罚 |
| --- | --- |
| E1 | 开局生命 -50% |
| E2 | 传送门半径 -50% |
| E3 | 坠落伤害 +100%，可致死 |
| E4 | 敌人移速 +40% |
| E5 | 治疗量 -50% |
| E6 | 敌人掉金币 -20% |
| E7 | 敌人伤害 +40% |
| E8 | 受到的一部分伤害变成永久损血（最大生命被削） |

日蚀不加玩家攻击。它只让同一套物品构筑面对更陡的曲线。E8 会让「堆最大生命」贬值，逼你改走护盾、屏障、无敌、不挨打。

## 3. 开局选择：难度、角色、神器

### 3.1 难度系数

公开常用公式：

```
PlayerFactor = 0.7 + 0.3 × 玩家数          （1 人时 = 1.0）
TimeFactor   = 0.0506 × 难度值 × 分钟数
StageFactor  = 1.15 ^ 已完成关卡数
DifficultyCoefficient = (PlayerFactor + TimeFactor) × StageFactor
```

| 难度 | 难度值 | 额外规则 |
| --- | --- | --- |
| 毛毛雨 Drizzle | 1 | 开局自带「更艰难的时代」，回血更厚 |
| 暴风雨 Rainstorm | 2 | 基准难度 |
| 季候风 Monsoon | 3 | 回血更薄，曲线更陡 |
| 日蚀 Eclipse | 3.5 | 再叠加上面 8 条 |

敌人生命近似：

```
敌人生命 = 基础生命 × DifficultyCoefficient × 精英倍率
```

敌人伤害增长明显慢于生命（补偿系数 / 弱幂），所以后期是「血皮厚、一下打不死你，但你要砍很久」。

玩家自己：

```
玩家生命 ≈ 基础生命 + (等级 - 1) × 每级生命
玩家伤害 ≈ 基础伤害 + (等级 - 1) × 每级伤害
```

每级生命通常约是基础生命的 30%，每级伤害约是基础伤害的 20%。只靠升级，玩家是斜线，敌人是指数。当局永久加成必须靠物品把玩家也变成指数。

### 3.2 精英倍率（常用公开值）

| 档 | 例子 | 生命 | 伤害 |
| --- | --- | --- | --- |
| T1 | 燃烧 / 过载 / 冰冻 / 愈合 | ×4 | ×2 |
| T2 | 孔雀石 / 天界 | ×18 | ×6 |
| 完美 / 虚空侵蚀 | 月精英、虚空精英 | 同 T2 量级，另加规则 | 另加规则 |

荣耀神器等于整局按精英倍率打，掉落也更好。

### 3.3 角色基础面板的设计分工

公开常见基准（突击兵一类远程）：约 110 生命、每级 +33，12 伤害、每级 +2.4。坦克型会把生命抬到 160–200（装卸工、阿克里德、多功能枪兵），输出仍靠物品而不是面板。

工程师的炮塔、多功能枪兵的双主手、船长的信标，都是「技能把物品再复制一遍」，不是面板更高。

## 4. 局内永久：物品经济

物品是 RoR2 真正的当局永久加成。捡到就一直在，可以无限叠，直到这局结束。

### 4.1 从哪来

| 来源 | 给什么 | 代价 |
| --- | --- | --- |
| 小 / 大 / 传奇箱 | 白 / 绿 / 红 | 金币，价格随难度涨 |
| 装备箱 | 主动装备 | 金币 |
| 打印机 | 指定同稀有度物品 | 塞 3 个同稀有度 |
| 拆解器 | 同稀有度废料 | 毁掉那一件 |
| 大锅 | 3 白换 1 绿，5 绿换 1 红 | 废料或成品 |
| 虚空摇篮 | 虚空物品 | 掉血 / 诅咒，并腐蚀对应普通物品 |
| 月箱 / 月店 | 月物品、月装备 | 月币 |
| 净化池 | 珍珠 / 虹彩珍珠 | 交出月物品 |
| 秩序神龛 | 某一稀有度全变成同一种 | 多样性清零，单件叠到极限 |
| 战斗 / 鲜血 / 森林神龛 | 物品或血上限 | 清一波怪，或扣血 |
| 传送门 Boss | 黄物品（Boss 独有） | 打完 Boss |
| 3D 打印机 + 命令神器 | 自选构筑 | 牺牲随机性 |

当局构筑不是「点技能树」，而是**用箱子、打印机、虚空、月店四条管道改背包**。

### 4.2 稀有度在设计什么

| 颜色 | 稀有度 | 叠层在干什么 | 典型结果 |
| --- | --- | --- | --- |
| 白 | 普通 | 线性数值，永远不亏 | 攻速、移速、暴击、格挡、近战加成 |
| 绿 | 罕见 | 新机制，或把白的规则放大 | 导弹、闪电链、跳跃次数、装备充能 |
| 红 | 传说 | 改规则 | 双触发、复活、面具小鬼、暴击伤害翻倍 |
| 黄 | Boss | 某个 Boss 的能力变成物品 | 石巨人节瘤、甲壳虫腺体、Halcyon 种子 |
| 蓝 | 月 | 强效果 + 硬副作用 | 伤害翻倍但血减半；装备自动放但冷却变长 |
| 紫 | 虚空 | 吃掉对应白 / 绿，换成另一套公式 | 安全空档替换格挡；多段闪电替换连锁闪电 |
| 橙 | 装备 | 主动，默认 1 槽 | 导弹、电容、回收、卵、扫描 |

白装是后期主力，不是过渡垃圾。一局 20 个注射器，比 1 个红装更能决定 DPS。这和 20MTD「同名不叠、必须点下一节点」相反。

### 4.3 叠层四种算法

| 算法 | 公式直觉 | 例子 |
| --- | --- | --- |
| 线性 | 效果 × 层数 | 士兵注射器：每层 +15% 攻速 |
| 双曲 | `1 - 1 / (1 + c × 层)`，逼近 100% 但到不了 | 更艰难的时代格挡、震撼手雷眩晕 |
| 指数 | `倍率 ^ 层` | 塑形玻璃：伤害 ×2 / 层，生命 ×0.5 / 层 |
| 阈值 / 上限 | 叠到帽或改判定 | 注入每层 +100 生命上限；透镜 10% 暴击 / 层，超过 100% 的部分浪费，除非再接暴击伤害 |

还有一层所有击中物品都吃的隐藏系数：

```
实际触发率 ≈ 物品写明的概率 × 这次攻击的 Proc Coefficient
```

鞭刀、锯枪、部分持续射线的 proc 很低，看起来「物品不生效」。突击兵点射、女猎人箭、阿克里德撕咬的 proc 接近 1，最能喂白绿触发器。

### 4.4 虚空腐蚀

虚空物品不是「又一个绿」。它会**吃掉**背包里对应的那一件普通物品，整组层数按虚空自己的公式重算。

| 虚空 | 吃掉 | 公式怎么变 |
| --- | --- | --- |
| 安全空档 Safer Spaces | 更艰难的时代 | 格挡概率 → 受伤后一段时间无敌，再进入冷却 |
| 哭泣真菌 Weeping Fungus | 旺盛真菌 | 站着回血 → 冲刺回血 |
| 针刺 Needletick | 三尖匕首 | 流血 → 崩溃（虚空 Dot） |
| 等离子虾 Plasma Shrimp | AtG 导弹 | 概率导弹 → 护盾存在时必发 |
| 多段闪电 Polylute | 尤克里里 | 弹射闪电 → 单目标多段 |
| 溶酶体电池 Lysate Cell | 燃料电池 | 装备充能 +1 → 特殊技能多 1 充能 |
| 虚空焰 Voidsent Flame | 鬼火 | 击杀掉火 → 第一次打满血掉火 |
| 深海花 Benthic Bloom | 四叶草 | 额外触发 → 定期把低级物品升到更高级 |

虚空是「改公式」，不是「加一层」。和 20MTD 的书类似，但代价是把你已经叠起来的白 / 绿吃掉。

| 野牛牛排 Bison Steak | 白 | 最大生命 |
| 注入 Infusion | 绿 | 击杀加生命上限，每层有帽 |
| 老化鹿角 / 护甲件 | 绿 | 护甲，减伤双曲 |
| 再生蜷曲 Regenerating Scrap | 绿 | 进打印机当免费材料 |

日蚀 E5 / E8 会打治疗和最大生命。这时护盾、屏障、无敌、格挡比「再 +100 HP」值钱。

### 5.5 装备循环

| 物品 | 稀有度 | 做什么 |
| --- | --- | --- |
| 燃料电池 Fuel Cell | 绿 | 装备充能 +1，并减冷却 |
| 溺亡手势 Gesture of the Drowned | 月 | 装备冷却 -50%，强制自动释放 |
| 灵魂催化剂 Soulbound Catalyst | 红 | 击杀减装备冷却 |
| 脑干细胞 Brainstalks | 红 | 击杀精英后技能无冷却 |
| 瓶装混沌 Bottled Chaos | 红 | 用装备时再随机放一个 |

电容、预制子加速器、导弹发射器、回收器、卵，都靠这条循环从「按一下」变成「一直在放」。

### 5.6 月物品：交易，不是升级

| 物品 | 你得到 | 你失去 |
| --- | --- | --- |
| 塑形玻璃 Shaped Glass | 伤害 ×2 / 层 | 生命 ×0.5 / 层 |
| 超然 Transcendence | 生命全转护盾，护盾量更高 | 不再有生命回复 |
| 溺亡手势 Gesture of the Drowned | 装备冷却减半，自动释放 | 失去手动控制时机 |
| 易碎王冠 Brittle Crown | 打人掉钱 | 挨打丢钱 |
| 尸体花 Corpsebloom | 治疗更强 | 治疗变慢，有速率帽 |
| 纯净 Purity | 技能冷却大幅下降 | 所有物品触发率下降 |
| 自我中心 Egocentrism | 环绕球 | 定期吞掉其他物品 |
| 异端套（视界 / 钩 / 步 / 精髓） | 换成异端技能 | 永远失去原技能槽 |

月物品和 20MTD 的玻璃之书、玻璃大炮符文是同一设计家族：**用生存换公式**。塑形玻璃是指数，两层就是 4 倍伤害、1/4 生命。

### 5.7 Boss 黄物品

传送门 Boss 有机会掉自己的能力：

- 石巨人 → 泰坦节瘤（生命、回血）
- 甲壳虫女王 → 女王腺体（甲壳虫守卫）
- 游荡者 → 创世纪回路（低血新星）
- 远古利莫里亚 / 岩浆蜗 → 熔火穿孔者
- 小恶魔霸主 → 充能穿孔者
- 合金虔信者 → Halcyon 种子（合金卫士）
- 黏土沙丘行者 → 淤泥瓮

黄物品是「把刚才那个 Boss 装进背包」，不是通用乘区。

### 5.8 主动装备

同时只能带 1 个（燃料电池加充能次数，不加槽）。设计职责：

- 爆发：预制子、导弹、电容
- 机动：卵、花瓶、奶菊
- 控制：皇家电容、哀伤雕像
- 经济：扫描器、金炸弹、执行卡
- 作弊级规则：回收器（改物品）、奖杯号角（指定 Boss 黄装）

装备不是被动永久，但「冷却接近 0」之后，它在当局里的手感接近常驻光环。

## 6. 角色技能：触发器，不是天赋树

RoR2 没有 20MTD 那种 25 棵 4 节点树。角色只提供 4 个技能。物品不看你是谁，只看你能不能打出高频、范围、击杀、暴击、近战这些事件。

| 角色 | 默认触发器 | 物品最吃哪条 | 常见换槽 |
| --- | --- | --- | --- |
| 突击兵 | 双枪点射，proc 干净 | 攻速、暴击、一切击中物 | 手雷把核从单体改成范围 |
| 女猎人 | 移动自动开火 | 攻速、暴击、移速 | 齐射换爆发；弩炮换站桩 |
| 盗贼 | 背后暴击、大招重置 | 爆发、重置、暴击 | 亡命之徒改成叠层赌暴击 |
| 多功能枪兵 | 双主手 + 运输模式 | 弹幕、设备、钉枪攻速 | 过载模式吃短时间无敌输出 |
| 工程师 | 炮塔复制背包 | 所有物品 × 炮塔数 | 地雷 / 热蜂换控制或补伤害 |
| 工匠 | 冰火雷法术 | 暴击、冷却、离子 | 离子涌把机动和输出合成 |
| 佣兵 | 连段、冲刺、暴露 | 冷却、范围、近战加成 | 斩风换成远程剑气 |
| 雷克斯 | 自残换强技能 | 回血、过量治疗、荆棘 | 种子弹幕换安全输出 |
| 装卸工 | 速度进拳头 | 移速、击杀、近战 | 带电拳把范围接到钩索 |
| 阿克里德 | 毒 / 枯萎 | 感染、击杀爆炸 | 枯萎换更高直伤更少 Dot |
| 船长 | 信标改规则 | 轨道、装备、团队 | 骇入信标改经济 |
| 磁轨炮手 | 弱点、充能 | 暴击、弱点、后坐 | 冰充能换控制 |
| 虚空恶鬼 | 腐化槽切两套技能 | 伤害阈值、回血、护盾 | 腐化技能吃爆发窗 |
| 探寻者 | 魂体连携 | 控制、团队、冷却 | 风暴 DLC 负荷 |
| 大厨 | 煎切油的连段 | 点燃、范围、攻速 | 料理顺序就是 combo |
| 伪子 | 石质近战、长线成长 | 生命、月、近战 | 关卡内还会再变强一截 |
| 漂泊者 | 废料和临时物品 | 打印机、废料、经济 | DLC3 的物品核 |

工程师是特例：他不是「技能强」，是「把你当局所有永久加成乘以炮塔数量」。这是 RoR2 里最接近 20MTD「书」的角色级规则。

## 7. 常见组合

稳定 combo 都是同一条事件对齐，再决定要不要用月 / 虚空改公式。

| 路线 | 怎么接 |
| --- | --- |
| 弹幕核 | 注射器 + 透镜 + 三尖 / 黏弹 + 尤克里里 / AtG + 四叶草。突击兵、女猎人、钉枪 MUL-T、工程师炮塔 |
| 击杀核 | 汽油 + 鬼火 + 仪式匕首 + 开心面具。清小怪，对 Boss 弱，要另接撬棍 / 穿甲弹 |
| 暴击核 | 透镜堆到 100% + 预知本能 + 镰刀 + 裂脾 + 瞄准镜。磁轨炮手、女猎人齐射、盗贼背后 |
| 装备核 | 燃料电池 + 溺亡手势 + 灵魂催化剂 + 脑干细胞。电容 / 预制子变成光环 |
| 玻璃核 | 塑形玻璃 × N + 超然或神盾。和 20MTD 玻璃之书同族，日蚀 E8 极难活 |
| 虚空核 | 安全空档 + 哭泣真菌 + 等离子虾。用新公式替换老白绿，不要两套混着叠 |
| 异端核 | 四件异端换掉 4 个技能槽，角色差异被抹平，物品核自己转 |
| 炮塔核 | 工程师 + 任意强力背包。打印机把废料洗成同一件，炮塔吃满层 |
| 移速拳 | 装卸工 + 羊蹄 / 饮料 / 羽毛 / 鹌鹑。速度进蓄力拳，和站桩暴击互斥 |
| 站桩回血 | 旺盛真菌 + 战旗 + 工程师泡盾。虚空后改哭泣真菌，改成边冲刺边回 |
| 秩序赌狗 | 秩序神龛把全部白变成注射器或透镜。多样性清零，单核拉满 |

不要同时开三条半截核。RoR2 允许无限叠，但背包格和打印机材料是有限的；命令神器只是把「赌」改成「选」，不会让你同时满叠所有核。

## 8. 和 20MTD 对照

| | 雨中冒险 2 | 黎明前 20 分钟 |
| --- | --- | --- |
| 跨局永久 | 解锁角色、物品、技能、神器；月币 | 符文阶数，直接进当局面板 |
| 局内永久形状 | 可无限堆的白 / 绿 / 红 | 25 棵短树 + 书 |
| 同类叠加 | 白装靠叠层成为后期主力 | 基本不叠同名，走下一节点 |
| 新机制来源 | 绿 / 红 / 月 / 虚空，1 件入手 | 树的第 1 个节点、枪进化、书 |
| 角色的职责 | 4 个技能当触发器，物品通用 | 角色被动 + 3 天赋，路线绑死 |
| 防爆炸 | 倒衰减 + 世界难度比玩家涨得快 | 树短、20 分钟、选项少 |
| 玻璃流 | 塑形玻璃、玻璃神器 | 玻璃大炮符文、玻璃之书 |
| 元素流 | 汽油 / 冰火带 / 工匠技能 | 火雷冰树 + 元素之书 + 对应角色 |
| 召唤流 | 炮塔、腺体、Halcyon、无人机 | 龙 / 幽灵 / 虫 + 独宠互斥 |
| 失败方式 | 曲线把你压死，或月物品副作用 | 点错树、站桩和风筝互殴 |

20MTD 是选职业路线：枪提供触发器，树接系统，书锁死规则。RoR2 是堆引擎：角色提供触发器，白装把频率拉高，绿装加新事件，红装改判定次数，月 / 虚空改公式。难度系数保证再强的引擎也会在某一分钟不够用，除非你还在继续叠。
