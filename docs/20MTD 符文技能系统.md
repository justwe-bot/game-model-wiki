# 20 Minutes Till Dawn 符文与技能系统

数据来自本机 Steam 安装：

`20MinutesTillDawn.app/Contents/Resources/Data`

对照文件：`Assembly-CSharp.dll`（`flanne.*`）、`resources.assets` 本地化表（605 条）、`Powerup` 167、`RuneData` 24、`GunEvolution` 33、`PowerupTreeUIData` 25。

局内升级、书、角色天赋、枪进化都是**当局永久**，过完一局清零。只有符文是**跨局永久**。

---

## 1. 系统分层

| 层级 | 是什么 | 何时生效 | 过局是否保留 |
| --- | --- | --- | --- |
| 符文 | 进战斗前买阶，每条 0–5 阶 | 整局 | 保留阶数 |
| 角色被动 | 选人自带 | 整局 | 否 |
| 角色天赋 | 宝箱开出，该角色 3 个天赋里随机 | 开出后整局 | 否 |
| 枪进化 | 选枪后的 3 选 1 变体 | 选后整局 | 否 |
| 升级树 | 升级时点的 25 棵 4 节点树 | 点后整局 | 否 |
| 书 | 恶魔交易：局内拾取后弹出 3 本随机书三选一 | 选后整局 | 否 |
| 魂心 / 信仰守护 | 额外心或挡伤，可再转化 | 获得后整局 | 否 |

设计不是随机抽一堆独立 buff，而是：

`枪的触发器 × 某一棵树 × 书 / 角色天赋 × 符文底子`

20 分钟点不完 25 棵树。黑暗 10 起少 1 个升级选项、黑暗 12 起减经验，树更尖，必须弃线。

## 2. 跨局永久：符文

进战斗前花钱买，分进攻（`SwordRuneTree`）/ 防守（`ShieldRuneTree`）。本机读到 **24 条** `RuneData`，对应菜单里两页 × 四行 × 三条。符文给底子或一次保命，不给新武器。

局内升级树**没有等级**：每个 `Powerup` 标准模式只能点一次。真正带阶的是符文。

### 2.0 阶、花费、行锁

| 规则 | 数据 |
| --- | --- |
| 字段 | `RuneData.level`（当局存档）、`costPerLevel`（每升 1 阶的固定价） |
| 上限 | 24 个 `RuneUnlocker.maxLevel` 全是 **5** |
| 买法 | 文案：鼠标左键长按购买；`holdToUnlockTime = 1.0` 秒 |
| 效果 | 按当前阶缩放，文案写「/ 阶」或「/ 级」，同一套 `level` |
| 无尽 | 「升级可以多次选择；符文不可用」 |

每一页 4 行，每行 3 条。后排看 `RuneRowUI.levelRequirement`，要先攒够该页已买符文的总阶：

| 行 | 解锁门槛 | 每阶价 | 单条满 5 阶总价 | 一行 3 条满阶 |
| --- | --- | --- | --- | --- |
| 1 | 0 | 1350 | 6750 | 20250 |
| 2 | 5 | 3150 | 15750 | 47250 |
| 3 | 10 | 6300 | 31500 | 94500 |
| 4 | 15 | 12800 | 64000 | 192000 |

一页 12 条全满 = 354000，两页全满 = 708000。第一行 3 条各买到 2 阶（总阶 6）就能开第二行；继续把前两行买到合计 10 阶开第三行，合计 15 阶开第四行。

## 4. 开局：枪与进化（武器科技分支）

武器科技就是**枪进化**：选枪时从该枪 3 个进化分支里挑 1 个。本机读到 44 条 `flanne.GunData` = 11 把基础枪 + 33 条进化枪，`flanne.GunEvolution` 33 条，每条挂在基础枪的 `gunEvolutions` 列表下。选枪菜单 `GunMenu` 恰好列 11 把。

每条分支 = 换一份枪面板（数值可能改）+ 一组触发器效果（`statChanges` / `effects`）。进化改开火规则，不进 25 棵升级树。

| 死神镰刀 | Terminus | 换弹完成后大范围旋转，4 倍子弹伤害并施加诅咒 | 无 |
| 神光之刃 | Terminus | 50% 几率对击中敌人造成 20 点惩戒 | 无 |
| 风武之刃 | Instant | 伤害随移速加成增加 | 无 |

### 4.3 分支设计套路

33 条分支不是随机配的，反复出现 8 种套路：

1. **移速吃加成**：疾风之箭 / 疾风之刃 / 风武之刃。三把武器各留一条移速出口，配移速树 + 动力转换符文。
2. **元素附加**：火力载荷 / 汽油炸弹 / 狱火蝙蝠 / 暗影蝙蝠 / 神光之刃。把枪挂进燃烧 / 冰冻 / 诅咒 / 惩戒体系。
3. **命中效果联动**：雷霆万钧 / 魔法喷雾。让非常规弹道（回收箭、孢子花）也能吃 OnHit 树。
4. **单发重击**：蓄力爆射 / 火焰流星 / 神箭召唤 / 炸弹魔箭。弹量或射速换倍率。
5. **弹药管理**：快速换弹 / 超频效应 / 首尾齐射。围绕弹匣位置做文章。
6. **分裂多发**：集束炸弹 / 腹背御敌。加弹丸数。
7. **弹道改造**：量子螺栓 / 花刀乱舞 / 喷射急流。改穿透 / 弹射 / 射程。
8. **功能生存**：防爆之盾 / 嗜血蝙蝠 / 近战射击。换生存或安逸。

同一把枪的 3 条分支通常分别对应「数值流 / 机制流 / 协同流」，保证任何升级路线都有适配的枪。

## 5. 局内永久：25 棵升级树

升级时五选一（黑暗 10 起四选一）。每棵树通常 4 个节点。先点出系统，再点乘区。

数值来自本机 `Powerup.statChanges` 和本地化描述。百分比走 `StatMod` 乘数加成，同名项相加，不是连乘。穿透、弹射、弹数、生命这类整数按 flat 位解读。标准模式每个节点只能拿一次，不会再升一级。

### 5.0 树状总览

#### 抽选规则

读 `DefaultPowerupProfile`、`PowerupGenerator` 和 `PowerupMenuState` 的 IL 得出，三条获取渠道互不重叠：

```text
局内获取渠道
│
├── 升级（五选一；黑暗 ≥10 四选一；夏娜每级可重置一次）
│     通用池 112 条 = 25 棵树 100 节点 + 跨树协同 12
│     └─▶ 夏娜·飞升：动态把 3 个光环碎片加进池
│
├── 宝箱（地图拾取，一次一个）
│     只从当前角色的 3 个天赋里抽，各一次
│
└── 恶魔交易（地图拾取）
      12 本书里随机 3 本，选 1 或离开，各一次
```

抽法的实现（`PowerupGenerator.GetRandom`）：

- 从池子里**均匀随机**抽，同一批不重复；没有倾向性权重
- 抽到的必须满足前置（`PrereqsMet`）：`anyPrereqFulfill = 1` 的前置**任一**已拿即可，`= 0` 的要**全部**已拿；判定对象是"本局已拿过"（`takenPowerups`），不是池子
- 拿过即从池中移除，标准模式每条只有一次；无尽模式可重复拿
- 前置没满足的协同节点**一直在池子里**，只是抽不到——不是"达成后才加入池"

#### 骨架

25 棵树共用一个骨架。连线读自每个 `Powerup` 的 `prereqs` 和 `anyPrereqFulfill`：

```text
            ┌── 左支线 ──┐
 入口节点 ───┤            ├──▶ 终点节点
            └── 右支线 ──┘
```

- 入口无前置；左右支线都要入口；终点 `anyPrereqFulfill = 1`，左右**任一**点出即可，不必全拿
- 例外一：**召唤攻速 / 召唤伤害**两棵树的入口本身有前置——先点出 魔法镰刀 / 魔法长矛 / 幽灵伙伴 / 龙卵 任一（同样是任一即可）
- 例外二：跑动射击的前置表是 `[疾走, 跑动射击]`（自引用脏数据），实际等价于只要疾走

## 7. 魂心与信仰守护

这两条是独立的生存资源，很多树和符文往上挂。

**灵魂之心**

- 额外的心，被打掉不会直接扣最大生命
- 有上限；灵力突破 / 魂身可以提高上限
- 可当乘区：灵魂之力是每持有 1 个魂心，子弹伤害 +10%；魂之骑士是每获得 1 个魂心，矛 +15 伤
- 可当武器：灵魂之链在失去魂心时削附近非 Boss 80% 生命

**信仰守护**

- 吸收一次伤害，默认 2 分钟再生（神圣守护改为 1 分钟，虔诚符文再减）
- 有盾时可以转输出（神圣冲击落雷）或转机动（神之祝福）
- 圣道树的惩戒可以反哺再生（以心证道）

## 8. 常见组合

稳定 combo 都是同一条乘区对齐，不要三棵半截树并行。

| 路线 | 怎么接 |
| --- | --- |
| 弹幕核 | 多重射击树 + 换弹树 + 韵律 / 虚无符文 + 狂热之书。用弹丸数、不耗弹、最后一发环形弹叠输出 |
| 元素核 | 火 / 雷 / 冰树 + 元素之书 + 对应角色（斯嘉丽 / 花火 / 有希）+ 蔓延符文。状态既是伤害，也是回弹、回血、射速的开关 |
| 召唤核 | 龙 / 幽灵 / 虫 / 魂 + 召唤攻速或召唤伤害树。独宠符文要求恰好 1 个召唤，和「再叫一只」互斥 |
| 玻璃核 | 玻璃大炮符文 + 玻璃之书 + 夏娜专家。输出翻倍，生存只靠不挨打、信仰守护、闪避 |
| 血转伤 | 坚韧之书 + 活力之书 + 黛蒙德倍化。心很少，但每点心都进伤害公式 |
| 站桩 | 站姿射击 + 静止之书方向。站着不耗弹、提高射速 |
| 风筝 | 疾风之书 + 移速树 + 疾风之箭 / 风武之刃。和站桩互斥 |

夏娜适合任何枪，因为她加速的是「选对树」。元素角色要和会上对应状态的枪或树对齐。莉莉丝、哈斯塔、瑞文、黛雪儿走召唤乘区。

## 9. 和雨中冒险 2 的差别（对照）

| | 20MTD | 雨中冒险 2 |
| --- | --- | --- |
| 跨局永久 | 符文阶数，直接进当局面板 | 解锁角色和物品进池，不直接加伤害 |
| 局内永久形状 | 25 棵短树 + 书 | 可无限堆叠的白 / 绿 / 红物品 |
| 同类叠加 | 基本不叠同名，走下一节点 | 白装靠叠层成为后期主力 |
| 新机制来源 | 树的第 1 个节点、枪进化、书 | 绿 / 红 / 装备 1 件入手 |
| 防爆炸 | 树短、20 分钟、选项少 | 倒衰减 + 世界难度系数比玩家涨得快 |

20MTD 是选职业路线：枪提供触发器，树接系统，书锁死规则。不是 RoR2 那种「同一件白针筒叠 20 层」。
