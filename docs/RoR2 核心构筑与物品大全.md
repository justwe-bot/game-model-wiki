## 1. 核心构筑（BD）

每条路线按「起步 → 放大 → 成型」三段列出，并给出适配角色和互斥件。所有路线共享一条前提：**实际触发率 ≈ 物品概率 × 该次攻击的 Proc 系数**。突击兵点射、女猎人箭、阿克里德撕咬 proc 接近 1；鞭刀、锯枪、持续射线 proc 很低，拿同样的物品效果差几倍。

### 1.1 弹幕核（Proc 触发流）

RoR2 的默认主核：高频主攻 × 一堆概率触发白绿 × 四叶草再掷。

| 阶段 | 物品 | 作用 |
| --- | --- | --- |
| 起步 | 士兵注射器 ×N | 攻速 +15%/层，把判定频率拉起来 |
| 起步 | 透镜 ×N | 暴击 +10%/层，10 层封顶 |
| 起步 | 三尖匕首、黏性炸弹 | 白色概率 proc，出血与爆炸 |
| 放大 | 尤克里里 | 25% 连锁闪电 80% 总伤，3(+2)/层 目标 |
| 放大 | AtG 导弹 Mk.1 | 10% 概率导弹 300%(+300%)/层 总伤 |
| 放大 | 聚焦晶体 / 撬棍 / 穿甲弹 | 近距 / 开场 / 对 Boss 三个乘区 |
| 成型 | 57 叶三叶草（四叶草） | 所有随机效果多掷 1 次取有利，全核质变 |
| 成型 | 有感情的肉钩 | 20%(+20%)/层 概率钩最多 10(+5) 个敌人 |
| 可选 | 灿烂巨兽、仪式匕首 | 全攻击范围化、击杀追加飞刃 |
| 可选 | 死亡印记 | 4 个 debuff 后全来源伤害 +50% |

- **适配**：突击兵、女猎人、钉枪 MUL-T、工程师（炮塔复制整套核）
- **不要拿**：纯净（全概率取更差结果）、光流肩甲（攻速腰斩）
- **要点**：成型标志是「打一下，屏幕上全是数字」。缺伤害时先补乘区（晶体/撬棍），再补 proc。

### 1.3 击杀核（链式爆炸）

击杀触发爆炸，爆炸再触发击杀，形成连锁。清屏速度极快，对单体 Boss 偏弱。

| 阶段 | 物品 | 作用 |
| --- | --- | --- |
| 起步 | 汽油 | 击杀点燃 12m(+4)/层，150% + 燃烧 150%(+75%) |
| 起步 | 鬼火 | 击杀熔岩柱 350%(+280%)/层，半径 12m(+2.4) |
| 起步 | 仪式匕首 | 击杀 3 把追踪匕首 150%(+150%)/层 |
| 放大 | 共振盘 | 7 秒杀 4 → 飞盘 300% 穿刺 + 1000% 爆炸 |
| 放大 | 霜冻遗物 | 击杀环绕冰暴 1200%/s，半径随击杀涨 |
| 放大 | 最开心的面具 | 7% 击杀召 1500% 伤害幽灵 30s(+30) |
| 放大 | 弹药带 | 击杀 18%(+10%) 概率重置全部技能 |
| 成型 | 老式断头台 | 精英低于 13%(+13%) 血直接处决，双曲 |
| 补 Boss | 撬棍、穿甲弹、聚焦晶体 | 链式对 Boss 无效，靠乘区补 |

- **适配**：突击兵手雷、阿克里德、清怪型构筑；「请原谅我」布娃娃装备能主动引爆击杀效果
- **要点**：恐惧首响 + 链式是前期最强清屏，但每局必须有对 Boss 的 B 计划。

### 1.5 玻璃核（月物品）

《黎明前 20 分钟》玻璃之书的同族：用生存换公式。

| 阶段 | 物品 | 作用 |
| --- | --- | --- |
| 核心 | 塑形玻璃 ×N | 伤害 ×2/层，生命 ×0.5/层，指数 |
| 生存替换 | 超然（月） | 生命全转再生护盾，+50%(+25%)/层 最大生命；治疗公式作废 |
| 生存替换 | 神盾（红） | 溢出治疗转屏障 50%(+50%) |
| 护盾核 | 个人护盾发生器、黄玉胸针、奇形蛋白石 | 护盾和屏障比血量值钱 |
| 保底 | 戴奥的挚友 | 复活保险，玻璃后被秒的唯一兜底 |

- **适配**：所有远程；近战（佣兵、装卸工）风险极高
- **不要拿**：尸体花（治疗被速率帽卡死）、医疗包系、狱火酊剂 / 发光陨石（自己半血会被自己的装备打死）
- **要点**：日蚀 E8 下基本不可玩（永久损血直接削护盾上限）；一两层是输出件，三层以上是另一个游戏。

### 1.7 异端核

四件异端套换掉全部技能槽，角色差异被抹平，物品核自己转。

| 件 | 换掉的槽 | 换成什么 |
| --- | --- | --- |
| 异端视界 Visions of Heresy | 主要 | 饥饿凝视：12 发追踪碎片弹匣，2s(+2)/层 重装 |
| 异端之钩 Hooks of Heresy | 次要 | 切割漩涡：蓄力 875%/s + 700% 爆炸 + 定身 |
| 异端之步 Strides of Heresy | 机动 | 暗影消逝：无敌 +30% 移速 + 回血 18.2%(+18.2%)，3s(+3) |
| 异端精髓 Essence of Heresy | 特殊 | 毁灭：叠层后无限射程引爆 300% + 120%/层 |

配套件：纯净（技能 CD -2s(+1)）、光流肩甲（CD -50% 攻速 -50%）、脑干、异形头（技能 CD -25% 指数）、溶酶体电池（特殊 +1 充能）。

- **要点**：单拿异端之步当无敌回血是常规操作；四件齐了才是「异端核」。换掉的主技能 proc 系数全部按异端技能重算，弹幕核白绿照样吃。

### 1.8 炮塔核（工程师）

工程师不是技能强，是把整套背包乘以炮塔数。

- 任意强力背包（弹幕核最佳）×2 炮塔
- 打印机 / 拆解器把杂件洗成同一件，炮塔吃满层
- 旺盛真菌 + 战旗 + 泡盾：经典站桩三件套
- 炮塔继承 proc 物品但不继承装备（装备核无效）

### 1.10 站桩回血核

旺盛真菌 4.5%(+2.25%)/s 治疗区 + 战旗 30% 攻速移速 + 工程师泡盾。虚空后换哭泣真菌，改成边冲刺边回。放大件：回春架（治疗 +100%/层）、神盾、恩库哈纳的意见（存治疗转骷髅伤害）。互斥：超然（治疗公式作废）。

### 1.11 秩序赌狗核

秩序神龛把全部同稀有度物品变成同一种（随机）。通常把所有白装赌成注射器或透镜，单核拉满。配套：牺牲 + 荣耀神器提高掉落量；打印机先把绿 / 红洗成想要的白。这是「背包格换深度」的极端玩法。

## 7. 餐点、临时物品与无稀有度件

### 7.1 餐点（合金 DLC，5 件）

终极套餐 + 高回复是概率流的合金 DLC 后期答案；炖菜把「溢出治疗」直接换成伤害，和神盾（溢出转屏障）同槽竞争。

### 7.2 临时物品机制（合金 DLC）

开启合金集群后，被动物品可获得**临时版本**（临时物品分发器、垃圾无人机等途径），到时消失：

- 临时件不可拆解，不可进 3D 打印机、净化池和大锅
- 红装「劣质复制器」让临时件多存 10s（+10）/层，是本机制的放大器
- 特卖星等少数物品不会出现临时版

### 7.3 无稀有度件（8 件）

内部机制与「事件已发生」的指示物：不可拆解、不可重堆、不可进打印机和净化池；部分可被合金 DLC 的流浪厨师（Wandering CHEF）料理「修复」。
