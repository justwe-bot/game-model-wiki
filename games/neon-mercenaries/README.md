# 霓虹佣兵

本分类收录 **29 套战斗角色外观**与 **42 把武器的原始音频资产**，按派系（灰熊 / 毒蝎 / 白鸽）组织，供角色档案页浏览。

> **验收状态：0/29 套角色通过完整验收，0/116 类动作通过验收，武器音频 0/42。** 本目录是资源归档与索引，不是已完成的质量成果。详见下方「验收状态」。

## 浏览方式

根目录的游戏选择器中选择「霓虹佣兵 / Neon Mercenaries」，或直接打开
`mercenaries.html?game=neon-mercenaries`（追加 `char=<slug>` 打开具体角色，如 `char=grizzly-01`）。

档案页提供：

- 按派系筛选的角色列表与关键词搜索；
- 每套角色的分区统计、验收状态、渲染预览与动作录像链接；
- 42 把武器的音频面板：逐事件列出可播放的原始叶片（数据来自 `weapon_audio/audio_index.json`）。

## 共享材质库的处理（重要）

源工程中每套角色的 `02_textures_materials` 下**并非各自持有一份贴图**，而是通过目录联接指向两个共享材质库。因此迁移时：

1. 复制**跳过全部目录联接**（已核验目标目录残留联接数为 0）；
2. 把两个共享库**各复制一份**到 `shared/`；
3. 各角色 `02_textures_materials` 中**不包含贴图本体**，需要贴图时请到 `shared/` 下按 depot 相对路径查找。

`soldier_material_depot` 后来并入了一批**材质依赖恢复 overlay**，新增 24,154 个文件、把该库从
6,550 个文件扩到 30,704 个。这次合并是**纯增量**：仓库里原有的 4,198 个文件一个没有被覆盖；
与源库同名的 2,352 个文件中，569 个仅差导出时间戳、其余 1,783 个字节完全相同，因此保留仓库内版本。
该 overlay 只补齐缺失的材质依赖，**不构成角色/材质/视觉/动作验收**。

## 武器音频（未验收）

`weapon_audio/` 收录 **42 把武器**的原始音频叶，保留每个武器的原始目录结构：

```text
weapon_audio/
├── audio_index.json                      # 事件 → 叶片索引（档案页读取）
├── weapon_sounds_batch_<stamp>.json      # 批次汇总
├── _migration_manifest.json              # 迁移清单
└── weapon_sounds_<code>_<stamp>/
    ├── attribution.json      # 归属与来源证据
    ├── event_routes.json     # 事件 → 叶片路由
    ├── packs/                # 该武器需要的音频容器
    └── wav/                  # .wav（PCM 原始）+ .opus（压缩副本）
```

**边界（必须随资产一起读）：**

- 这些是**原始音频叶**。选择器、随机化、增益、RTPC、空间化与分层**均未求值**，因此单个叶子
  **不是**最终运行时事件混音，也不主张任何单发时序或射速。
- **从未人工试听**，`accepted` 全为 `false`。
- 同一叶片可能被多个事件共享；`audio_index.json` 只把它归属给第一个事件，不会出现死链。
- 档案页播放的是 `wav/` 下的 PCM 原始文件，未经任何运行时混音处理。
